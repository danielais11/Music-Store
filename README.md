# Music-Store

The project is a Java-based music store application where users can browse and purchase music-related items such as CDs, vinyl records, instruments, and accessories.

The application provides a graphical user interface and includes the following features:

Browse available products
Add products to a shopping cart
Purchase items
Generate and save receipts as .txt files
View purchased items in a separate inventory scene
Manage product and inventory data
